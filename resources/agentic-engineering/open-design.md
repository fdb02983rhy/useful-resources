# OpenDesign

## Summary

A collaborative AI design workspace that connects briefs, design systems,
prototypes, media, and team feedback with coding-agent workflows.

## Why this was saved

- A reference for organizing reusable design assets and agent-assisted iteration
  in one project, beyond a single interface-generation prompt.

## Notes

### Source claims

- Studio supports interactive prototypes, presentations, generated images, and
  motion graphics, with previews and export workflows.
- Design systems, templates, skills, and plugins can be inspected and adapted.
- Integrations include skills, CLI and MCP access, native agent runtimes, and
  bring-your-own-key model endpoints.
- The project describes itself as local-first, offers a cloud service, and uses
  the Apache-2.0 license.

### Editor synthesis

Useful for comparing collaborative design-agent environments. Local-first does
not by itself guarantee that prompts or assets remain on-device: inspect the
selected model, cloud, and sharing configuration. Features were reviewed from
documentation, not tested through an installation.
