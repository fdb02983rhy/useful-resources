# Jailbreaks prompt collection

## Summary

A repository collecting model-targeted prompts, persona definitions, workspace
policies, agent instruction files, and harness configuration examples.

## Why this was saved

- A reference collection for examining instruction conflicts, persona framing,
  and prompt manipulation across model and agent instruction surfaces.

## Notes

### Source claims

- The README groups material by model family and provider, spanning open-weight,
  closed, and stealth models.
- Formats include system prompts, `AGENTS.md` files, persistent workspace
  policies, configuration blocks, and Ollama Modelfiles.
- The maintainers describe the collection as research and educational material
  and note that behavior depends on model versions and changing instruction systems.

### Editor synthesis

The README's target labels and compatibility descriptions are maintainer claims,
not independently verified results. This note preserves the repository as one
collection; prompts were not installed, executed, or tested for effectiveness.
