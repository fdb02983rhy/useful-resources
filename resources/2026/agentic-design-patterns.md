# Agentic Design Patterns

## Summary

A third-party repository pairing a 424-page book PDF with Jupyter notebooks for
21 agentic-system patterns. Its scope runs from chaining, routing, parallel work,
reflection, tools, planning, and multi-agent coordination through memory,
adaptation, MCP, recovery, human oversight, RAG, inter-agent communication,
optimization, reasoning, guardrails, evaluation, prioritization, and exploration.

## Why this was saved

- Offers a broad taxonomy for reviewing an agent design.
- Maps conceptual chapters to many framework-specific notebook examples.
- Can serve as a curriculum outline or an index for finding a pattern to explore.

## Notes

### Source claims

- The inspected tree contains one PDF, two README files, and 65 notebooks.
- Examples span Google ADK, LangChain and LangGraph, CrewAI, FastMCP, Vertex AI,
  OpenEvolve, and other tools.
- The README proposes a read, run, modify, and combine workflow for studying the patterns.

### Editor synthesis

The breadth is useful, but provenance and reproducibility need caution. The
repository owner is not the named book author, and the precise authorization to
redistribute the included book and notebooks was not established. The README says
the code is MIT licensed and refers to `LICENSE`, `requirements.txt`, and
`CONTRIBUTING.md`, but none were present in the inspected tree. Dependencies are
not pinned, and some examples rely on changing hosted APIs and credentials.

The notebook README also calls the set “58 notebooks,” while the reviewed tree
contains 65. Do not assume that rights covering any code also cover the included book.
