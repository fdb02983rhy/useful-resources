# fast.ai

## Summary

A practical deep-learning education and software hub. The site brings together
fast.ai's courses, the fastai library for PyTorch, nbdev, the *Practical Deep
Learning for Coders* book, and a long-running blog covering technical work,
education, advice, health, and AI's societal effects.

## Why this was saved

- Provides a code-first route into deep learning through courses, software, and
  worked examples.
- Keeps practical engineering material alongside writing about education and the
  social consequences of AI.
- Serves as a stable starting point for discovering fast.ai's current projects
  without splitting the site into separate resources.

## Notes

### Source claims

- The homepage currently points readers to *Practical Deep Learning for Coders*
  and *How to Solve It With Code*.
- Its software links include the fastai library for PyTorch and nbdev.
- The blog is organized across advice, AI in society, courses, education, health,
  and technical topics.

### Editor synthesis

This is best used as a discovery hub rather than a single linear curriculum.
Start with the course most relevant to the current goal, then use the library
documentation and blog as supporting references.
