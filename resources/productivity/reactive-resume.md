# Reactive Resume

## Summary

An open-source resume builder with document editing, customization, resume
checks, cover letters, and job-application tracking. It offers hosted and
self-hosted deployment paths.

## Why this was saved

- A practical reference for maintaining tailored career documents and application
  records with portable exports and control over hosting.

## Notes

### Source claims

- The inspected README describes live PDF previews, templates, custom sections,
  document versions, readability checks, and job-posting keyword matching.
- Import supports several document formats; export includes PDF, DOCX, Markdown,
  and JSON. Some import and writing features require a connected AI provider.
- Optional AI suggestions can be accepted or rejected. REST and MCP interfaces
  expose document and application workflows.
- Sharing includes public links and optional passwords. Self-hosting options
  include Docker and cloud deployments. The project is MIT-licensed.

### Editor synthesis

Useful for a repeatable application workflow, but a resume check is not a hiring
guarantee. Review public-sharing settings and AI-provider data handling before
uploading personal information. Documentation was inspected; no account or
deployment was created.
