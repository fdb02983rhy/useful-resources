# HackLLM Jailbreaks

## Summary

A browsable prompt archive organized by model family, version, and topic,
with model-specific and universal instruction collections.

## Why this was saved

- A reference for comparing prompt framing and agent instruction formats
  across models through a searchable catalog.

## Notes

### Source observations

- The page's interface data includes search, model-family and topic filters,
  prompt details, and a copy action.
- Topics include engineering, research, writing, and evaluation. Interface
  text is provided in English, Spanish, and Simplified Chinese.
- Prompt records include names, summaries, provider/model labels, and source
  filenames. The metadata identifies some records as censored placeholders.

### Editor synthesis

Useful as a collection for studying instruction manipulation and prompt design.
Model labels and descriptions are catalog metadata, not verified compatibility
or effectiveness results. No prompts were executed or tested.

### Retrieval

The text-only page exposed little content. Its public `copy.js` and `prompts.js`
assets were inspected on 2026-11-28 to establish the catalog structure. Browser
interactions were not tested. The collection is kept as one resource.
