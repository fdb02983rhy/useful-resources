# Agent evaluation

Resources about measuring, diagnosing, and improving AI-agent behavior.

- [Inside OpenAI's in-house data agent](../resources/2026/inside-openais-in-house-data-agent.md)
  — production context infrastructure and an execution-based approach to
  evaluating a data agent's generated SQL and results.
- [AI Agent Workshop Tokyo — AI Agent Auto Improvement](../resources/2026/ai-agent-workshop-tokyo-auto-improvement.md)
  — a feedback loop spanning annotation, offline evaluation, monitoring, and
  evidence-led prompt changes.
- [Demystifying evals for AI agents](../resources/2026/demystifying-evals-for-ai-agents.md)
  — practical guidance on tasks, isolated trials, mixed graders, transcripts,
  capability suites, and regression suites.
