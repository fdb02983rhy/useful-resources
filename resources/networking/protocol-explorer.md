# Protocol Explorer

## Summary

A browser-based educational resource for understanding internet protocols through
interactive lessons and packet-by-packet explanations. Its public description
emphasizes decoding packet contents byte by byte.

## Why this was saved

- A visual companion to networking study that connects protocol names with
  message exchanges and packet structure.

## Notes

### Source claims

- Listed topics include HTTP, HTTPS, TCP, UDP, IP, DNS, DHCP, ICMP, SMTP, POP3,
  IMAP, FTP, SSH, and TLS.
- The page describes animations showing packets travelling through a network;
  JavaScript is required to run the lessons.
- Metadata lists multiple languages, including English, Japanese, Simplified
  Chinese, and Traditional Chinese, and identifies the application as free.
- The site's HTML credits Dilum Sanjaya as its author.

### Editor synthesis

Useful for building intuition before reading protocol specifications or examining
real packet captures. Treat educational examples as simplified models rather
than exhaustive protocol references.
