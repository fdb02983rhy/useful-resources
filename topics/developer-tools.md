# Developer tools

Resources that support software-development workflows and environments.

- [git push no-mistakes](../resources/2026/no-mistakes.md) — an isolated,
  agent-driven quality gate between a local branch and its remote.
- [cmux](../resources/2026/cmux.md) — a programmable native macOS terminal for
  organizing parallel coding-agent sessions.
- [Ponytail](../resources/2026/ponytail.md) — a portable agent policy and toolset
  for reducing unnecessary implementation complexity.
