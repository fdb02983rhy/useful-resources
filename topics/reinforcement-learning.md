# Reinforcement learning

Resources about learning policies from rewards, including tool-using agents.

- [AI Agent Workshop Tokyo 2026, Part 1: Agentic RL](../resources/2026/agentic-rl-workshop-part-1.md)
  — an agent-training workshop covering environments, tools, reward contracts,
  GRPO and GSPO, rollouts, trace debugging, and safety.
- [The Hitchhiker's Guide to Agentic AI](../resources/2026/hitchhikers-guide-to-agentic-ai.md)
  — foundations and implementation guidance spanning classical RL, RLHF, PPO,
  DPO, GRPO, reward modeling, reasoning, and trajectory-level agent training.
