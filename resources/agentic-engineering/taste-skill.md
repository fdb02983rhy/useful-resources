# Taste Skill

## Summary

An agent-skill repository for designing websites and app screens with explicit
art direction, reference imagery, and browser-based review. It currently centers
on the `design-taste-frontend` skill.

## Why this was saved

- A reference for making visual decisions explicit in coding-agent workflows.
- Connects design guidance to rendered-page inspection and iterative correction.

## Notes

### Source claims

- The workflow interprets the brief, selects a design direction, uses credited
  imagery, checks multiple viewport widths, and revises screenshot findings.
- Dashboards and app screens have a separate path with checks for navigation,
  tables, charts, and responsive layouts. Existing-page redesign starts with an
  audit.
- Scripts require Node 22+ and Chrome, Edge, or Chromium; image discovery requires
  network access. The README states that no API keys are needed.
- Guidance is framework-independent. Older companion skills have moved to other
  repositories; this repository is MIT-licensed.

### Editor synthesis

Useful as a design-review workflow, not a guarantee of visual quality. Review
accessibility, asset-license obligations, and brand fit independently. This note
records documentation, not a tested installation or benchmark.
