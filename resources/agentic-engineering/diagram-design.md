# Diagram Design

## Summary

An agent skill for producing editorial-style diagrams as standalone HTML with
inline SVG, using a consistent visual system and optional brand matching.

## Why this was saved

- A reference for turning architecture, processes, and comparisons into portable
  publication graphics with explicit layout and styling constraints.

## Notes

### Source claims

- The inspected README lists 45 diagram types, including architecture,
  sequences, data models, timelines, and charts, with light and dark variants.
- Output opens directly in a browser and can be exported to SVG or PNG.
- Existing Mermaid, draw.io, and Excalidraw diagrams can be redrawn; brand
  onboarding adapts palette and typography.
- The README acknowledges model-dependent layout and recommends Mermaid for
  frequently changing diagrams maintained as source in Git. The license is MIT.

### Editor synthesis

Best evaluated as a publishing-oriented visual workflow rather than a replacement
for every diagram source format. Check semantic accuracy, labels, and layout
after generation. This is documentation review, not a tested installation.
