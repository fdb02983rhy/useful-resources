# Agent skills

Reusable instruction packages and workflows for AI agents.

- [Grill Me](../resources/2026/grill-me.md) — a stateless, dependency-aware
  interview for resolving a plan before execution.
- [Grill with Docs](../resources/2026/grill-with-docs.md) — a repository-aware
  interview that records vocabulary and selected architectural decisions.
- [Ponytail](../resources/2026/ponytail.md) — cross-harness guidance and commands
  that bias coding agents toward the minimum necessary implementation.
